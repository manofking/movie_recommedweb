# movie_recommedweb



### 🎬 Movie Recommendation Web Service (풀스택 영화 추천 웹)

**TL;DR** — IMDB API 기반의 백엔드(FastAPI)와 리액트(React) 프런트엔드로 구축된 영화 추천 풀스택 웹 서비스입니다. AWS EC2 인스턴스 환경에서 GitLab Runner와 Docker를 연동하여 CI/CD 자동화 배포 파이프라인까지 구축했습니다.

---

### 📌 주요 특징 (Key Features)

* **IMDB API 연동**: 최신 및 인기 영화 데이터를 실시간으로 가져와 추천 제공
* **FastAPI 백엔드**: 파이썬 기반의 빠르고 경량화된 RESTful API 서버 구축
* **React 프런트엔드**: Node.js 환경에서 사용자 친화적인 동적 SPA UI 구현
* **Docker & CI/CD**: GitLab Runner와 Docker를 활용한 AWS EC2 자동 배포 환경 구성

---
